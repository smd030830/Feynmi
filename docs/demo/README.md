# 시연 자료와 대본 (FM-063)

두 TXT는 이 저장소의 시연을 위해 직접 작성한 한국어 자료다. 외부 저작물이나 실제 개인정보를 포함하지 않는다. PRD에서 지원하는 UTF-8 TXT 입력을 사용하며 PDF·PPTX·OCR 품질 검증을 대신하지 않는다.

- `01-process-thread.txt`: 프로세스와 스레드, 공유 자원, 경쟁 상태와 동기화.
- `02-transaction.txt`: 송금 예시를 이용한 트랜잭션과 ACID, 커밋·롤백.

## 시작 전

전용 시연 계정, 실제 Firebase 설정, DB·저장소와 AI 환경변수를 확인한다. 키는 화면이나 저장소에 노출하지 않는다. [배포 절차](../deployment.md)에 따라 공개 환경 확인이 끝나야 공개 시연 준비 완료로 표시한다. AI 설정이 없으면 분석 실패와 재시도 안내가 나타나는 것이 정상이며 개념 생성 성공을 연출하지 않는다.

## 약 7분 시연 대본

1. **로그인·홈 (1분)**: “제 자료를 기준으로 제가 설명한 내용을 확인하는 서비스입니다.” 가입 인증과 닉네임 설정을 거쳐 홈을 연다. 처음이라면 빈 상태와 프로젝트 생성 버튼을 보여 준다.
2. **프로젝트·자료 (1분)**: `운영체제 기초` 프로젝트를 만들고 첫 TXT를 올린다. “자료 내용이 외부 AI로 전송된다는 안내를 확인하고 동의합니다.” 진행 단계와 원본 파일 행을 보여 준다. 다음으로 `데이터베이스 기초` 프로젝트에 두 번째 TXT를 올린다. 분석 완료를 기다리고 실제 개념 목록을 확인한다. 개념 이름과 개수는 생성 결과에 따라 달라진다.
3. **설명·추가 질문 (2분)**: 첫 프로젝트에서 스레드 또는 관련 개념을 선택한다. “스레드는 한 프로세스 안의 실행 흐름이고 같은 프로세스의 자원을 공유합니다.”처럼 일부만 설명한다. 실제 요소 판정과 질문을 읽고, 빠진 내용을 자신의 말로 답한다. 예를 들어 “각 스레드는 자기 스택과 실행 위치를 가집니다. 공유 값을 동시에 바꾸면 경쟁 상태가 생길 수 있어 보호가 필요합니다.”라고 보완한다. 정해진 점수나 추가 질문 발생을 약속하지 않는다.
4. **결과·근거 (1분)**: 완료 후 점수·상태·점수 변화·맞은 점·빠진 점·틀린 점과 근거를 보여 준다. 근거의 TXT 위치 표시는 문서 분할 기준이며 실제 종이 쪽 번호와 다를 수 있음을 설명한다. 다음 추천으로 새 세션이 열리는지 확인한다.
5. **기록·설정 (1분)**: 학습을 중단하고 홈의 통계·취약 개념·주간 위젯과 학습기록을 연다. 완료·중단 기록의 차이를 확인한다. 프로필 메뉴에서 설정으로 이동해 학습 목표와 알림 설정을 바꾼다.
6. **오류 안내 (1분)**: 전용 환경에서만 네트워크를 잠시 끊어 안내와 다시 시도를 확인한다. 운영 중인 다른 사용자의 설정이나 자료를 변경하지 않는다.

## 리허설 기록

| 검증 | 현재 증거 | 남은 확인 |
|---|---|---|
| 두 원본의 한국어 텍스트 추출·청크 분할 | 로컬 실제 파서와 청크 분할 검사 | 다른 형식·OCR 검증은 별도 |
| 업로드·원본 저장·실패·재시도 | 로컬 Chrome → FastAPI → GCS 에뮬레이터 흐름 확인 | 실제 클라우드 저장소 |
| 학습 시작·결과·기록·홈·설정 | 별도 PostgreSQL과 로컬 서명 토큰 기반 브라우저 검사 | 실제 Firebase 로그인 |
| 샘플 → 실제 AI 개념 추출 → 답변 평가 | 미완료 | AI 키를 연결한 전체 리허설 |
| 공개 URL 핵심 흐름 | 미완료 | 배포 환경·계정 권한·실제 시연 |

AI가 생성한 평가를 미리 작성한 결과로 대체하지 않는다. 외부 연결이 없을 때는 자료와 로컬 검증 범위를 소개하고 전체 리허설이 남았음을 밝힌다.
