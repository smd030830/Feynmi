> 문서 버전: v0.4 (초안) / 수정일: 2026-10-19
> 기준 문서: PRD.md v0.4 (축소된 MVP)

## 0. 범례와 전제

- **우선순위(MoSCoW)**: M = Must (MVP 필수), S = Should (여유 시), C = Could, W = Won't (MVP 이후)
- **SP**: 스토리포인트 (1, 2, 3, 5, 8). 상대 추정치이며 팀 인원 확정 후 재산정 필요
- **스프린트**: 1주 단위, 1개월 = 스프린트 4개
- **MVP 완료 기준**: 업로드 → 개념 추출 → 설명 → 판정 → 피드백 → 홈 확인이 끝까지 동작
- 스토리 형식: `FM-번호` / 유저스토리 / 인수 조건(AC)

## 4. 스프린트 계획 (1주 × 4, 초안)

| 스프린트 | 목표 | 항목 | 합계 SP |
|---|---|---|---|
| S1 | 기반, 로그인, 업로드 | FM-001, 002, 003, 004, 010, 011, 020, 050 | 24 |
| S2 | 자료 분석 (개념 추출까지) | FM-012, 021, 022, 023, 051, 053 | 23 |
| S3 | 핵심 가치 (설명, 판정, 피드백) | FM-030, 031, 032, 033, 034, 035, 052, 054 | 31 |
| S4 | 홈, 안정화, 배포, 시연 준비 | FM-040, 041, 042, 060, 061, 062, 063 | 21 |

- Must 합계 약 99 SP.
- S3는 판정 품질에 따라 지연될 가능성이 가장 크다. S2 종료 시점에 개념 추출이 안정적이어야 S3에 진입할 수 있다.
- 가치 검증 시점: S3 종료 시 "설명 → 판정 → 피드백" 데모가 가능해야 한다.

## 5. 완료 정의 (Definition of Done)
- 인수 조건 충족
- 코드 리뷰(PR 승인 1명 이상) 및 CI 통과
- LLM 관련 기능은 JSON 스키마 검증과 오류 처리 포함
- 스테이징 환경에서 동작 확인

## 6. 확정 필요 항목
PRD 12장 "미확정 사항"과 동일합니다. 남은 것은 **임베딩 모델**(FM-051에 영향)과 OpenAI 공식 문서 기준 모델 ID/파라미터 확인(FM-050에 영향)입니다.
