# 결정 이력

v0.5(2026-10-22)에서 미확정 사항과 문서 간 충돌을 모두 확정했다. v0.6(2026-10-22)에서 아키텍처 설계([architecture.md](architecture.md))에 필요한 구현 결정을 추가했다. v0.7(2026-10-22)에서 Figma Make 시안([design-system.md](design-system.md))의 화면 구성을 반영해 범위를 넓혔다. 현재 미확정 항목은 없다.

| 항목 | 결정 |
|---|---|
| 로그인 수단 | 이메일/비밀번호 + 구글만. 시안의 네이버, 카카오는 MVP 제외 |
| 이메일 가입 | 이메일 인증 필수, 비밀번호 재설정 제공 |
| 생성 모델 | `gpt-5.6-luna`, 작업별 `reasoning.effort` (9.2) |
| 임베딩 모델 | `text-embedding-3-small` (1536차원) |
| 추가 질문 횟수 | 세션당 최대 3회 (v0.4의 [가정] 2회에서 변경) |
| 피드백 공개 시점 | 진행 중에는 맞은/빠진 부분만, 종료 시 4파트 전체 (FR-3.3) |
| 취약 개념 범위 | 오개념 > 부분 이해 > 미학습 (미학습 포함) |
| 세션 단위와 재학습 | 1세션 = 1개념, 재학습은 새 세션에서 새로 평가 (6.2) |
| 세션 중단 | 마지막 판정 반영 후 중단 처리 (6.2) |
| 업로드 제한 | 50MB, 300쪽/슬라이드 |
| 개념 수 | 자료당 5~10개 |
| 원본 파일 | Cloud Storage 비공개 버킷에 보관 |
| 배포 | Vercel + Cloud Run + Cloud SQL |
| 약관 | 이용약관, 개인정보 처리방침 정적 페이지 MVP 포함 |
| 서비스명 표기 | Feynmi |
| 사용자 흐름 | "개념 목록 수정" 삭제 (MVP 제외 항목과 충돌 해소) |
| (v0.7) 프로젝트 | 프로젝트 도입. 이름+설명(선택), 자료 여러 개, 개념은 자료별 추출 후 합산, RAG는 프로젝트 범위 (FR-1.0, FR-5.2) |
| (v0.7) 이해도 점수 | 핵심 요소 판정 가중합(충족 1, 부분 0.5, 누락·모순 0). 프로젝트·전체는 학습한 개념 평균 (6.1⑥) |
| (v0.7) 점수 변화 | 세션 안 변화만 표시. 기간별 추이는 MVP 제외 |
| (v0.7) 결과 화면의 단계 | 점수 구간 대신 개념 상태 + 이해까지 남은 핵심 요소 수 (FR-3.5) |
| (v0.7) 학습기록 | 세션 상세 열람 MVP 포함. 중단 세션은 대화와 진행 중 범위만 (FR-4.5) |
| (v0.7) 홈 | 통계, 다음 학습 추천(시안의 "이어서 학습하기" 대체), 프로젝트, 취약 개념 섹션 (FR-4.3) |
| (v0.7) 학습 통계 | 학습일 = 판정 있는 날(KST), 주 = 월~일 7칸 (FR-4.9) |
| (v0.7) 이메일 가입 | 시안 단계 UI + Firebase 방식(이메일·비밀번호 → 인증 링크 → 닉네임). 6자리 코드 방식은 쓰지 않음 (FR-4.1) |
| (v0.7) 설정 | 시안 전체 구현: 계정, 로그인 기록(시각·브라우저/OS만), 전체 로그아웃, AI 질문 난이도(질문 문체만), 앱 내 알림, 주간 목표, 회원 탈퇴(즉시 전체 삭제) (FR-4.6~4.9) |
| (v0.7) 시안의 MVP 제외 요소 | 네이버·카카오, DOC·DOCX·TXT·이미지 업로드, 자료 관리(삭제) 메뉴, 추천 카드의 예상 시간·상승폭은 제거 |
| (v0.7) 모바일 | MVP에서 제외, PC 브라우저만 지원 (7장) |
| (v0.7) 디자인 값 | 글자 최소 12px로 확대, 캡션 글자색 진하게, 오개념은 빨강, 시안 SVG 아이콘 사용, 글꼴은 `next/font` ([design-system.md](design-system.md)) |
| (v0.7) 세부 초기값 | 닉네임 1~20자, 인증 메일 재발송 대기 60초, 로그인 기록 최근 10건 표시, 학습 목표 기본 주 3일 |
| (v0.6) 분석 비동기 처리 | Cloud Tasks + 백엔드 내부 워커 엔드포인트 (9.1) |
| (v0.6) 업로드 경로 | Signed URL 직접 업로드. Cloud Run 요청 본문 32MB 제한 회피 (9.4) |
| (v0.6) 세션 이탈 감지 | 클라이언트 중단 요청 + 서버 지연 정리, 사용자당 진행 중 세션 1개 (6.2) |
| (v0.6) 중단 세션 공개 범위 | 종료 요약 없음, 진행 중과 같은 범위만 공개 (6.2) |
| (v0.6) 진행 중 상태 표시 | 판정마다 개념 상태 표시 (FR-2.3, FR-3.3) |
| (v0.6) 취약 개념 정렬/개수 | 같은 상태 안에서 최근 판정순, 개수 제한 없음 (FR-4.3) |
| (v0.6) RAG/재시도 수치, 개념 추출 입력, 평가 응답 방식, API 호출 구조 | 9.4 |
| (v0.6) ORM, PDF 파서, API 타입 공유, 로컬 GCS/Firebase | 9.1 |
| (2026-10-26) 백엔드 타입 검사 | pyright (standard 모드). CI에서 ruff, pytest와 함께 실행 (9.1) |
