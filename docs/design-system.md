# Feynmi 디자인 시스템

> 문서 버전: v0.2 / 수정일: 2026-10-22
> 기준 문서: [prd.md](prd.md) v0.7
> 출처: Figma Make [Feynmi](https://www.figma.com/make/Iege5S6x8S1AbiuzbGakR4/Feynmi), 내보내기 `Feynmi.make`(2026-10-22 07:27 UTC, 코드 커밋 `54333b4`)의 `src/index.css`, `src/App.tsx`

이 문서는 Figma Make 시안의 디자인 값(1~8장)과 화면 구성(9장)을 정리한다. 시안 원값 중 다음은 결정에 따라 바꿨다(PRD 12장 v0.7).

- 글자 크기를 최소 12px로 키웠다.
- 캡션 글자색을 더 진한 색으로 바꿨다.
- 오개념에 빨강을 배정했다.
- 글꼴은 `next/font`로 불러온다.
- PC 전용이며 모바일 레이아웃은 다루지 않는다.

기능, 규칙, 수치는 PRD가 기준이다. 이 문서는 그것을 화면에 어떻게 보여주는지만 정한다.

## 2. 타이포그래피

### 2.1 글꼴
`next/font/google`로 불러오고 CSS 변수로 노출한다. 시안처럼 Google Fonts CSS를 `@import`하지 않는다.

| 변수 | 글꼴 | 굵기 | 용도 |
|---|---|---|---|
| `--font-sans` | Noto Sans KR | 400, 500, 600, 700, 800 | UI 전체 |
| `--font-brand` | Plus Jakarta Sans | 700, 800 | 로고 글자 |

- 시안의 프로젝트 이니셜(∫ 같은 기호, Georgia)은 이름의 첫 글자로 바꾸고 `--font-sans` 700으로 표시한다.
- `font-synthesis: none`.

### 2.2 크기 체계
최소 크기는 12px이다. 시안의 작은 크기(7~11px)는 크게, 큰 크기는 적당히 키웠다.

| 토큰 | 크기 / 행간 / 자간 | 굵기 | 시안 원값 | 용도 |
|---|---|---|---|---|
| `display` | 40 / 1.4 / -1.5px | 700 | 36 | 로그인 브랜드 문구 |
| `title-1` | 30 / 1.4 / -0.8px | 700 | 27~29 | 페이지 제목, 인증 폼 제목 |
| `title-2` | 24 / 1.45 / -0.6px | 700 | 22~23 | 단계 카드 제목, 결과 개념명, 통계 숫자 |
| `title-3` | 20 / 1.45 / -0.3px | 700 | 18 | 세션 질문, 결과 점수 |
| `heading` | 18 / 1.4 | 700 | 16 | 섹션 제목 |
| `subheading` | 16 / 1.45 | 700 | 13~15 | 패널 제목, 카드 제목, 현재 질문 |
| `body-lg` | 15 / 1.75 | 400 | 12~14 | 소개 문장, 답변 입력, 대화 본문 |
| `body` | 14 / 1.65 | 400~600 | 10~11 | 목록 제목, 일반 본문, 버튼(작은) |
| `caption` | 13 / 1.55 | 400~600 | 9 | 보조 설명, 메타 정보, 배지 |
| `micro` | 12 / 1.5 | 500~700 | 7~8 | 범례, 꼬리표, 단축키, 글자 수 |
| `eyebrow` | 12 / 1.4 / +1.6px | 800 | 11 | 대문자 라벨 (`LEARN BY EXPLAINING`) |
| `button` | 15 / 1 | 700 | 14 | 기본 버튼 (작은 버튼은 `body` 600) |

- 굵기 용도: 본문 400, 보조 라벨 500, 버튼·메뉴 600, 제목·강조 700, 아이브로 800.
- 레이아웃 치수(3장)는 시안 값을 유지한다. 글자가 커져서 넘치는 곳(배지, 칩, 행 높이)만 키운다.

## 7. 아이콘과 로고

### 7.1 아이콘
시안의 인라인 SVG를 그대로 옮긴다(`components/icon.tsx`, 원본은 시안 `src/App.tsx`의 `Icon`).

- 공통 속성: `viewBox 0 0 24 24`, `fill none`, `stroke currentColor`, `stroke-width 1.8`, `stroke-linecap round`, `stroke-linejoin round`, `aria-hidden`. 기본 크기는 20px이다.
- 아이콘 이름: `home`, `folder`, `chart`, `settings`, `arrow`, `book`, `spark`, `plus`, `file`, `check`, `clock`, `target`, `chevron`, `brain`, `more`, `mail`, `user`, `link`, `shield`, `bell`, `logout`, `upload`, `image`.
- 시안에 없는 아이콘이 필요하면 같은 속성으로 추가한다. 예: 닫기(`x`), 경고(`alert`), 새로고침(`retry`), 자물쇠(`lock`).
- 학습 흐름 아이콘: 개념 `book` indigo, 설명 `brain` lavender, 질문 `spark` cyan, 이해 `target` green.

### 7.2 로고
- 마크: 42×42 viewBox의 "F" 형태. 브랜드 그라데이션으로 채우고, 흰 곡선(불투명도 .42, 굵기 1.4)을 겹친다. 표시 크기는 사이드바 35px, AI 아바타 21~24px다. 원본 경로는 시안 `Logo` 컴포넌트에 있으며 `apps/frontend/public/logo-mark.svg`로 옮긴다.
- 글자: `Feynmi`, Plus Jakarta Sans 22px, 자간 -1px, `#27314d`.

## 9. 화면 구성

라우트와 화면의 대응이다. 각 화면의 데이터와 규칙은 괄호 안의 PRD 절을 따른다. "제거"는 시안에 있지만 PRD 범위 밖이라 넣지 않는 요소다.

### 9.1 공통 레이아웃 (로그인 이후 화면)
- **사이드바**: 로고 → 내비(홈, 프로젝트, 학습기록, 설정) → 주간 학습 위젯 → 프로필.
  - 주간 위젯: "이번 주 학습", "목표 N일 중 M일", 월~일 7칸. 학습한 날은 indigo 칩, 오늘은 테두리 강조 (FR-4.9).
  - 프로필: 아바타, 닉네임, 이메일, 더보기 메뉴(프로필 관리 → 설정의 계정, 설정, 로그아웃).
- **상단 바**: 왼쪽에 화면 이름(아이브로 성격의 `caption`), 오른쪽에 상태 점 + "오늘의 학습 준비 완료".
- 진행 중 세션에서 사이드바 메뉴로 이동하면 세션을 중단한다 (PRD 6.2). 확인 모달은 띄우지 않는다.

### 9.2 로그인 `/login`
- 2열: 왼쪽 브랜드 패널(로고, `LEARN BY EXPLAINING`, "알고 있다고 생각한 것을, *직접 설명해보세요.*", 학습 흐름 다이어그램, 인용문), 오른쪽 폼.
- 폼: "Feynmi에 오신 것을 환영합니다." → Google로 계속하기 → "또는" 구분선 → 이메일 로그인 폼(9.3) → 약관 동의 문구(이용약관·개인정보 처리방침 링크).
- 제거: 네이버, 카카오 버튼.

### 9.3 이메일 로그인 폼 (시안에 없음, `/login`에 포함)
- 별도 화면 없이 로그인 화면(9.2)의 구분선 아래에 바로 놓는다: 이메일 입력, 비밀번호 입력, 로그인 버튼, "비밀번호를 잊으셨나요?" 링크, "처음이신가요? 회원가입" 링크.
- 이메일 미인증 계정으로 로그인하면 회원가입 ② 단계로 보낸다 (FR-4.1).

### 9.4 회원가입 `/signup` (FR-4.1)
- 로그인 화면(9.2)과 같은 2열 틀을 쓴다. 왼쪽은 브랜드 패널, 오른쪽에 "이전으로"(① 단계만), "회원가입" 제목, Auth progress(이메일 / 인증 / 프로필), 단계별 폼을 둔다.
- ① 이메일: 이메일, 비밀번호, 비밀번호 확인 → "인증 메일 받기".
- ② 인증: `shield` 단계 아이콘, "이메일로 보낸 링크를 눌러 인증해주세요.", 보낸 주소 표시, 도움줄("메일이 오지 않았나요? 다시 보내기", 재발송 대기 카운트다운) → "인증 완료했어요"(인증 상태를 다시 확인. 아직 미인증이면 inline alert).
- ③ 프로필: 닉네임 입력, "닉네임은 설정에서 언제든 변경할 수 있어요." → "Feynmi 시작하기".
- 폼 아래(② ③ 단계): "Feynmi는 꼭 필요한 정보만 안전하게 보관합니다."
- 시안의 6자리 인증번호 입력은 링크 확인 방식으로 바꿨다.

### 9.5 비밀번호 재설정 `/reset-password` (시안에 없음)
- 인증 단계 카드: 이메일 입력 → "재설정 메일 보내기" → 완료 문구와 로그인으로 돌아가기.

### 9.6 소셜 온보딩 `/onboarding` (FR-4.1)
- 구글 첫 로그인 시. 환영 링 + 아바타, `WELCOME TO FEYNMI`, 연결된 계정 박스(Google, 이메일), 닉네임 입력(구글 표시 이름으로 미리 채움) → "Feynmi 시작하기".

### 9.7 홈 `/` (FR-4.3, FR-4.8, FR-4.9)
위에서부터 다음 순서로 배치한다.
1. **인사 줄**: 시간대 인사 아이브로(좋은 아침이에요 / 좋은 오후예요 / 좋은 저녁이에요), "안녕하세요, {닉네임}님", "오늘은 무엇을 이해해볼까요?", 오른쪽에 날짜·요일.
2. **앱 내 알림 배너**(학습 알림이 켜져 있고 조건에 맞을 때만): 목표 알림, 복습 알림. 복습 알림의 행동 버튼은 해당 개념의 새 세션을 시작한다.
3. **히어로**: "Feynman Learning" 라벨, 문구, "지금 학습하기"(취약 개념 1순위로 새 세션. 취약 개념이 없으면 "새 프로젝트 만들기"), 학습 순환 장식(개념 → AI 질문 → 이해 분석).
4. **학습 개요**(3열 Stat card):
   - 전체 이해도: 점수(%), 미니 링
   - 학습 개념: N개, 보조 "이번 주 N개"
   - 학습 일수: 최근 30일 N일, 보조 "N일 연속 학습 중"
   - 섹션 머리 오른쪽에 "지난 30일 기준".
5. **다음 학습 추천**(시안의 "이어서 학습하기" 카드 형식): 개념 이니셜 타일, 아이브로 "다음 학습 추천", 개념명, 프로젝트명, 현재 이해도 진행 바 + 상태 배지, "학습하기" 버튼. 추천할 개념이 없으면 숨긴다.
6. **나의 프로젝트**(4열 그리드): 프로젝트 카드(이니셜 타일, 이름, 최근 학습 개념, 프로젝트 이해도 %, 진행 바, 상태 분포 바) + "새 프로젝트" 점선 카드(새 프로젝트 모달). 섹션 머리 오른쪽 "전체 보기" → `/projects`.
7. **취약 개념**(Panel + Concept row 목록): 행마다 개념명, 프로젝트명, 상태 배지, 점수. 정렬은 FR-4.3, 개수 제한 없음. 행을 누르면 새 세션. 없으면 Empty state("모든 개념을 이해했어요").
- 제거: 전체 이해도의 "+8% 이번 달".
- 프로젝트가 하나도 없으면 4~7 대신 Empty state("첫 프로젝트를 만들어보세요")를 보여준다.

### 9.8 새 프로젝트 모달 (FR-1.0)
- 제목 "새 프로젝트", 이름(필수), 설명(선택, 여러 줄), 미리보기(자동 배정될 색의 이니셜 타일), 만들기 → 프로젝트 상세의 학습자료 탭으로 이동.

### 9.9 프로젝트 목록 `/projects`
- 페이지 제목 "프로젝트", 홈과 같은 프로젝트 카드 그리드(최근 학습순) + 새 프로젝트 카드.

### 9.10 프로젝트 상세 `/projects/[id]` (FR-1.0~1.8, FR-4.5)
- **브레드크럼**: 프로젝트 › {이름}.
- **헤더**: 큰 이니셜 타일(64px), 아이브로 "PROJECT · 자료 N개", 이름(`title-1`), 설명, 상태 분포 바, Progress ring(프로젝트 이해도), "학습 시작하기"(프로젝트의 취약 개념 1순위로 새 세션. 없으면 비활성).
- **탭**: 개념 N / 학습자료 N / 학습기록 N.
- **개념 탭**: 2열.
  - 왼쪽 Panel "개념 이해도": 범례 4상태, Concept row 목록(자료 순 → 자료 안 개념 순). 행 설명은 개념의 기준 설명 첫 줄이고, 행을 누르면 새 세션을 시작한다. 분석 중인 자료가 있으면 목록 위에 "자료 N개 분석 중" inline alert를 띄운다.
  - 오른쪽 위 "학습자료" 카드: 최근 자료 File row, 정보 박스(추출 개념 N개 / 채점 요소 N개), "학습자료 살펴보기"(soft). 더보기 메뉴에는 "학습자료 추가"만 둔다.
  - 오른쪽 아래 "최근 학습" 카드: 최근 세션 3개(개념, 날짜, 점수), "전체 보기" → 학습기록 탭.
- **학습자료 탭**:
  - 머리: "학습자료", 안내, "학습자료 업로드" 버튼.
  - Upload zone: 끌어다 놓기와 여러 파일 선택 지원. 안내 "PDF · PPTX", "파일당 50MB, 300쪽/슬라이드까지".
  - 업로드된 파일 목록(최신순): 상태는 업로드 중 / 추출 중 / 개념 생성 중(진행 중 점) / 분석 완료(성공 점, "N쪽 · 개념 N개") / 실패(위험 점 + 실패 사유 + "다시 시도" 버튼).
  - 아래 안내: `shield` + "업로드한 자료는 {프로젝트} 프로젝트의 개념 분석과 질문 생성에만 사용됩니다."
  - 첫 업로드 때 외부 AI 전송 동의 모달을 띄운다 (FR-1.8).
- **학습기록 탭**: Record row 목록(9.13과 같음, 이 프로젝트만).
- 제거: 아이브로의 분야 라벨(MATHEMATICS), 학습자료 "관리" 메뉴, 파일 행 더보기 메뉴, DOC·DOCX·TXT·PNG·JPEG 안내.

### 9.11 세션 `/sessions/[id]` (F2, FR-3.3, 6.2)
- **상단**: 브레드크럼(프로젝트 › 개념), 오른쪽 "학습 종료"(soft) → 확인 모달("지금 종료하면 이 학습은 이어할 수 없어요") → 중단 처리 후 프로젝트 상세로 이동.
- **제목 줄**: 아이브로 `FEYNMAN 학습`, 개념명(`title-1`), 오른쪽 "추가 질문 N회 남음".
- **Stepper 5단계**: 개념 설명 → 추가 질문 1 → 추가 질문 2 → 추가 질문 3 → 정리. 이해에 도달하면 남은 질문 단계를 건너뛰고 정리로 간다.
- **본문 2열**(왼쪽 가변, 오른쪽 270px):
  - 왼쪽 "설명하며 이해하기": 머리 오른쪽에 평가 중일 때만 "대화 분석 중" 배지. 타임라인에 라운드마다 AI 질문 → 학습자 답변 → 피드백 노트(진행 중 공개 범위: (a) 맞은 부분, (b) 힌트)를 쌓는다.
  - 왼쪽 하단 Composer(sticky): 현재 질문 띠("현재 질문"), 답변 입력("내 말로 설명해보세요..."), 꼬리줄("학습자료를 보지 않고 설명해보세요", 글자 수, `Ctrl+Enter`, "설명 보내기"), 아래 학습자 노트("정답을 맞히려 하지 않아도 괜찮아요. 지금 이해한 만큼 자신의 언어로 설명해주세요.").
  - 오른쪽 "현재 이해 상태" 패널(sticky): 아이브로 "실시간 분석", 개념 상태 배지, 요소 목록(요소 문구 + 판정 배지, 1.5), 현재 이해도(점수 + 진행 바), "자료에서 확인되지 않음" 진술이 있으면 info box, "연결된 학습자료"(근거 자료명 · 쪽/슬라이드).
- 평가 중에는 Composer를 비활성하고, 오른쪽 요소 배지를 "이해 확인 중"으로 바꾼다. 평가가 실패하면 inline alert + 다시 보내기.
- 세션이 완료되면 결과 화면으로 자동 이동한다. 시안의 "이해도 분석 결과 보기" 떠 있는 버튼은 넣지 않는다.

### 9.12 결과 `/sessions/[id]/result` (FR-3.5)
- **머리**: 브레드크럼, 아이브로 `LEARNING COMPLETE`, "학습 결과", "설명 속에 드러난 이해를 분석했어요.", 오른쪽 "YYYY. MM. DD · N분 학습".
- **점수 영역**(결과 면, 3구획):
  - 왼쪽: "학습 개념", 개념명, 핵심 보완 포인트 요약 1~2줄, 점수 변화("+N%p 상승" / "N%p 하락" / "변화 없음", "N%에서 시작했어요")
  - 가운데: 큰 Progress ring(최종 점수)
  - 오른쪽: "현재 단계" → 개념 상태 배지, "이해까지 남은 핵심 요소 N개" + 진행 바(충족 핵심 요소 비율). 이해면 "모든 핵심 요소를 충족했어요"
- **분석 3열**: 잘 이해한 부분 (a, 성공) / 보완이 필요한 부분 (b, 주의) / 잘못 이해한 부분 (c, 위험). 항목이 없으면 "해당 없음".
- **AI 분석 요약**(Panel): (d) 보완 설명. 아래에 "자료에서 확인되지 않음" 진술 목록.
- **다음 학습 추천**: 배지 "다음 학습 추천", 이니셜 타일, 아이브로(상태 이유 문구, 예: "오개념이 있는 개념이에요"), 개념명, 프로젝트명, "다음 학습 시작하기". 추천이 없으면 숨긴다.
- **아래 행동**: "프로젝트로 돌아가기"(ghost), "학습 결과 저장됨 ✓"(soft, 상태 표시).
- 학습기록에서 연 완료 세션은 같은 화면 아래에 "대화 다시 보기"(접힘, 9.11의 타임라인 읽기 전용)를 더한다.
- 제거: 추천의 "약 10분", "예상 이해도 +19%". "이해를 80%까지 끌어올릴 다음 개념" 문구는 상태 이유 문구로 바꿨다.

### 9.13 학습기록 `/records` (FR-4.5)
- 페이지 제목 "학습기록", 안내 "설명한 개념과 결과를 다시 확인하세요.", 오른쪽 "총 N회 학습" 칩.
- Record row 목록(최신순): 상태 원(완료 체크 성공 / 중단 `clock` 비활성), 개념명, "프로젝트 · 날짜 · N분 학습", "이해도", 점수, chevron.
- 완료 세션 → 9.12. 중단 세션 → 중단 세션 상세.
- **중단 세션 상세** `/sessions/[id]`(읽기 전용): 상단에 "중단된 학습" 배지, 9.11의 타임라인만 표시(Composer와 오른쪽 패널의 점수·상태 제외, 진행 중 공개 범위), 아래 "이 개념 다시 학습하기"(새 세션).

### 9.14 설정 `/settings` (FR-4.6, FR-4.7)
- **머리**: 아이브로 `MY FEYNMI`, "설정", "계정과 학습 환경을 관리하세요.", 오른쪽 "마지막 저장 · {상대 시각}".
- **프로필 카드**: 큰 아바타(이미지 변경 단추), "프로필", 닉네임, 이메일, 태그(로그인 수단 "Google 연결됨" 또는 "이메일 계정", "이메일 인증 완료"), "프로필 수정"(soft) → 프로필 모달.
- **2열**: 왼쪽 설정 내비(sticky, 계정 / 로그인 및 보안 / 학습 설정 / 서비스, 누르면 해당 섹션으로 스크롤), 오른쪽 섹션 카드.
  - 계정: 프로필(닉네임 표시 → 프로필 모달), 연결된 계정(로그인 수단 표시만), 이메일 인증 상태.
  - 로그인 및 보안: 로그인 기록("최근 · 브라우저/OS" → 로그인 기록 모달, 최근 10건), 모든 기기에서 로그아웃(danger 버튼 → 확인 모달 → 로그인 화면).
  - 학습 설정: AI 질문 난이도(Segmented: 기본 / 깊이 있게), 학습 알림(Toggle), 학습 목표(Stepper control: 주 1~7일).
  - 서비스: 이용약관, 개인정보 처리방침(정적 페이지로 이동), 회원 탈퇴(위험 글자 → 탈퇴 모달).
- **아래**: "변경사항은 자동으로 저장됩니다.", "대시보드로 돌아가기"(soft). 값이 바뀌면 즉시 저장하고 토스트를 띄운다.
- **프로필 모달**: 아바타 미리보기, 이미지 선택(JPG/PNG, 2MB 이하) / 이미지 삭제, 닉네임 입력(1~20자), 저장.
- **회원 탈퇴 모달**: 위험 아이콘, "탈퇴하면 모든 프로젝트, 자료, 학습기록이 즉시 삭제되며 복구할 수 없어요.", "탈퇴"를 입력해야 활성되는 danger 버튼.

### 9.15 이용약관 `/terms`, 개인정보 처리방침 `/privacy` (FR-4.4, 시안에 없음)
- 인증 보조 화면 배경(장식 원) + 상단 로고·"돌아가기" + 폭 760px 흰 카드. 제목 `title-1`, 본문 `body-lg`, 절 제목 `heading`. 로그인 여부와 관계없이 열린다.

### 9.16 외부 AI 전송 동의 모달 (FR-1.8, 시안에 없음)
- `shield` 타일, "자료가 외부 AI(OpenAI)로 전송돼요", 전송 목적(개념 추출, 답변 평가)과 범위 요약, 개인정보 처리방침 링크, "동의하고 업로드"(primary) / "취소".
